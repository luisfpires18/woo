# Release scope

Updated: 2026-10-05. Status: design documentation; no game implementation yet.

## Confirmed first-version direction

2026-10-05 explicit clarification: the many ideas describe an evolving game, not features to deliver all at once. The first playable version should be simple and fully medieval. Runes begin to emerge later as the user evolves the game. This supersedes any assumption that L1/L2/L3, Chaos/Order finale, magical armour transformations, flying mounts or every unique kingdom system must ship in version one.

The first version should express warfare, conquest and building appealing armies using ordinary medieval troops, default equipment and weapon/armour upgrades. Blacksmithing supports military progression; it is not a requirement for a crafting-dominated experience. First-alpha playable faction direction remains Arkazia, Veridor and Sylvara. Exact first-version buildings, units, combat and conquest scope still require definition; NPC outpost timing and naval features are not automatically first-release commitments. Preserve advanced concepts as future design material, not mandatory launch requirements.

Distinguish release progression (adding game systems over time) from seasonal progression (unlocking existing systems within a season). User has not yet decided whether rune emergence occurs during the first season, in a later season, or with a separate update. Do not convert this statement into an automatic first-season fantasy schedule or fixed release dates. The previously suggested 10-12-week Chaos/Order season arc is a future proposal, not the first-version specification.

## Alpha faction availability

Arkazia, Veridor and Sylvara playable. Draxys, Nordalh, Zandres and Lumus greyed out/unselectable. Drakanith NPC neutral and Moraphys NPC hostile are intended world roles; their exact first-version presence needs confirmation.

## Proposed minimal playable slice

Login, kingdom selection, one village, a small ordinary resource/building/unit set, weaponsmith/armorsmith upgrades, a basic talent choice, automatic combat, village ownership transfer, reports, and admin content/image editing. These are recommended slice components, not an approved final feature list.

## Later design material

Rune discovery, L1 Conduit, L2 Aspect/blood bonding, magical armour, L3 Chaos/Order, full naval warfare, water mounts, Eagle Raiders, underground routes, additional kingdoms and the Moraphys finale. Hero inclusion is undecided.

## Gate before implementation

Choose a small first roster and resolve the blocking medieval rules in [open questions](open-questions.md). A playable milestone needs explicit acceptance criteria and provisional balance values.
