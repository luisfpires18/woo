# Content catalogues

Updated: 2026-10-05. Status: design documentation; no game implementation yet.

## Status

No final unit, building, resource or recipe catalogue has been approved. The owner will provide rosters. Earlier supplied unit files are idea sources only. Veridor shipwrights/water mounts and Sylvara Eagle Raiders are future identity directions, not a first-version roster.

## Proposed unit record

Stable ID; kingdom; name/description; release availability; recruitment building/prerequisites; cost/time/upkeep; combat role; movement domain; armour class; default weapon; permitted upgrades/swaps; stats; counter conditions; sprite/image slot and fallback symbol. Rune fields are future extensions, not active first-version requirements.

## Proposed building record

Stable ID; kingdom/availability; category; slot rules; prerequisites; levels; costs/timing; effects; queue behaviour; capture/destruction behaviour; image slots/visual stages; fallback and interaction anchor.

## Proposed equipment/recipe record

Stable ID; class/category; compatible unit types; tier; materials; smith/talent requirements; duration; outcomes; stat effects; release availability; image/fallback. Bonded bearers and recoil are future fields when defined.

## Review gate

Each first-version entry needs confirmed identity, provisional balanced numbers, counter purpose, admin-editable fields and player-facing explanation. No entry should be marked implemented before code exists.
